# Code of conduct

## The short version

Be decent. Assume the other person is arguing in good faith about typography and
not about you.

## What is expected

- **Disagree about the text, not about the person.** Nearly every dispute here is
  a dispute about what a standards body prescribes or about whether a rule fired
  on prose that was already correct. Those are settleable questions. Bring the
  text and the citation.
- **A false-positive report is a contribution, not a complaint.** Someone taking
  the time to show that a rule is wrong is doing the work this project cannot do
  for itself. Treat it that way, on both sides.
- **Languages are not better or worse than one another.** French requires a
  narrow no-break space where German forbids one; Switzerland points its
  guillemets the other way from Germany. None of that makes a convention wrong,
  and a rule that treats one national standard as the default is a bug in this
  repo.
- **Assume a language barrier before assuming rudeness.** This project is about
  four languages and its issue tracker is in English, which is a second or third
  language for many of the people best placed to report a false positive.

## What is not

Harassment, insults, sustained disruption, publishing someone's private
information, and unwelcome attention of any kind. Also: dismissing a report
because of who filed it, and using a national or regional convention as a way to
have a go at the people who use it.

## Scope

Issues, pull requests, discussions and any other space this project uses,
including private contact that arises from participating in it.

## Reporting

Email **shbernal.01@gmail.com**. Reports go to the maintainer and stay private.
This is a small project maintained by one person: expect an acknowledgement
within a week and a plain answer rather than a process. Where the maintainer is
the problem, say so in the report; there is no committee to appeal to, but there
is a public record of how it was handled.

The maintainer may edit, hide or delete contributions that break this document,
and may block an account from the repository. Where that happens the reason will
be stated rather than left to be inferred.
